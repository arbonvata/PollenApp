# Pollen Tracker

Pollen Tracker is a hobby project designed to help users track local pollen levels.

## 🌍 Scope

*   **Geographic Limitation:** Currently, this application is functional **only in Sweden**.

## 🛠️ Configuration

*   **API Endpoint:** https://api.pollenrapporten.se/

## ✨ Development Standards

*   **Best Practices:** This project is built following modern Android development best practices, including using idiomatic Kotlin and leveraging Jetpack libraries.

## ⚠️ Disclaimer

**Please note:** This is a personal hobby project and is **not** of industrial or production quality. It is developed for learning and experimentation purposes. Features may be incomplete, and there are no guarantees regarding stability or long-term support.

## 🚀 Getting Started & Build Instructions

**To Build:**
1. Open the project in Android Studio.
2. Sync Gradle dependencies.
3. Run the `./gradlew :app:assembleDebug` task.

**To Run:**
1. Ensure an Android device or emulator is connected.
2. Click the green run arrow in Android Studio.
